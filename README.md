## Quick Start

1. **Check compatibility:** For PSP installation, verify that the console is running supported official system software, such as 6.60 or 6.61.
2. **Obtain the installer:** Download the appropriate FasterARK package from the project repository and extract it to the Memory Stick.
3. **Run the installer:** Launch FasterARK from the PSP interface and follow the project installation instructions. Consult the official documentation before applying a Custom IPL.

Official project resources:
- [ARK-5 Repository](https://github.com/PSP-Arkfive/ARK-5)

## FAQ

**1. What is ARK-5?**

ARK-5 is custom firmware for the PSP and the PSP emulation environment on PS Vita. It provides an expanded system environment with homebrew, plugin, and performance-related functionality.

**2. Is ARK-5 the successor to ARK-4?**

Yes. The ARK-4 repository directs users to ARK-5 as its successor. ARK-4 is archived, while ARK-5 is maintained in a separate repository.

**3. Does ARK-5 support PSP homebrew?**

The project provides a custom firmware environment with homebrew and plugin support. Compatibility may depend on the application and its requirements.

**4. Can ARK-5 be installed on PS Vita?**

ARK-5 includes support for the Vita's PSP emulation environment. Installation uses a separate workflow and additional requirements; follow the official FasterARK documentation.

**5. Where can I find installation instructions?**

Use the official ARK-5 Wiki and FasterARK repository for current installation packages, supported configurations, and update procedures.
